# 🏆 积分小当家 — 孩子家务/作业积分管理系统

一个让孩子爱上做家务、认真写作业的家庭奖励 App。家长发布任务、设置积分奖励，孩子认领任务、拍照打卡，家长审核后发放积分，支持调整积分和扣分。

**多设备联网同步 + 可安装的 PWA + 手机端友好界面**

---

## ✨ 功能特性

### 👨‍👩‍👧 家长端
- 📝 **发布任务**：选择类型（家务/作业）、填写名称说明、设置积分、指定孩子或开放认领
- 👦 **孩子管理**：添加多个孩子账户（独立账号密码、积分、头像颜色）
- ✅ **任务审核**：查看孩子上传的完成照片，通过或驳回，**通过时可调整实际发放积分**
- 🏆 **积分管理**：排行榜、积分流水、**手动加分/扣分模块**
- 📊 **任务管理**：按状态筛选（待认领/进行中/待审核/已完成）

### 👧 孩子端
- 🔥 **认领任务**：从任务池认领可认领的任务
- 📸 **拍照打卡**：完成任务后上传照片+备注
- 🏆 **我的积分**：查看当前积分和积分明细流水

### 🔄 通用
- 🔐 家长/孩子多账号，同一设备可切换
- 📱 **PWA**：可安装到手机主屏幕，像原生App一样使用，离线可用
- ☁️ **多设备同步**：数据存储在服务器，手机/平板/电脑都能用

## 🚀 快速开始（本地运行）

### 环境要求
- **Node.js 22+**（使用内置 SQLite，无需额外安装数据库）

### 安装与启动

```bash
cd child-points-app
cd server && npm install && cd ..

# 启动服务器
node server/index.js
```

启动后打开浏览器访问：**http://localhost:8080**

**默认家长账号**：用户名 `parent` / 密码 `123456`

> ⚠️ 首次登录后请到"孩子"页添加孩子账户，每个孩子用自己的账号登录。

---

## 📱 安装到手机（PWA）

### 手机浏览器访问
1. 在手机浏览器打开部署好的网址
2. 浏览器菜单选择 **"添加到主屏幕"**（iPhone Safari）或 **"安装应用"**（Chrome/Android）
3. 桌面上就会出现"积分小当家"图标，点击即可全屏使用

---

## ☁️ 云平台部署（实现多设备联网同步）

### 方案一：Docker 部署（推荐，任何云服务器/VPS/NAS）

```bash
# 构建并启动
docker compose up -d

# 或手动
docker build -t child-points .
docker run -d -p 8080:8080 -v $(pwd)/data:/app/data -e JWT_SECRET=你的密钥 child-points
```

数据保存在 `./data` 目录，重启不丢失。

### 方案二：腾讯云 CloudBase / 云托管
1. 在腾讯云开通 **云托管（CloudBase Run）** 或任意容器服务
2. 上传本项目，使用 `Dockerfile` 构建镜像
3. 分配公网访问域名
4. 家人通过该域名访问即可多设备同步

### 方案三：Node 平台（Railway / Render / Fly.io 等）
1. 推送到 GitHub
2. 在平台导入项目
3. 设置启动命令 `node server/index.js`
4. 绑定持久化卷到 `/app/data`（数据库）

## 🛠 技术架构

```
┌─────────────────────────────────────┐
│         前端 (PWA 单页应用)           │
│  public/  HTML + CSS + JS           │
│  manifest.json + sw.js (离线缓存)     │
└────────────────┬────────────────────┘
                 │ REST API (JSON)
┌────────────────▼────────────────────┐
│         后端 (Node.js + Express)     │
│  server/index.js  路由 + 认证(JWT)   │
│  server/db.js     SQLite 数据访问    │
└────────────────┬────────────────────┘
                 │
        ┌────────▼────────┐
        │   SQLite 数据库  │  data/points.db
        └─────────────────┘
```

### 数据表
| 表 | 说明 |
|----|------|
| `users` | 用户（家长/孩子），含积分 |
| `tasks` | 任务（家务/作业），含状态流转 |
| `submissions` | 孩子提交的完成照片和备注 |
| `points_log` | 积分流水（奖励/调整/扣分） |

### 任务状态流转
```
发布任务
  ├─ 开放认领 → pending(待认领) → 孩子认领 → claimed(进行中)
  └─ 指定孩子 → claimed(直接进行中)
        ↓
claimed → 孩子提交照片 → completed(待审核)
        ↓
completed → 家长通过 → approved(已通过，发积分)
         → 家长驳回 → claimed(退回重新做)
```

## 🔐 安全说明
- 使用 JWT 令牌认证（7天有效期）
- 密码使用 bcrypt 加密存储
- 家长接口（发布/审核/孩子管理/积分调整）仅家长账号可访问
- 生产环境务必修改 `JWT_SECRET`
